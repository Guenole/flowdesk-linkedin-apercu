# FlowDesk — maquette du module LinkedIn

Maquette cliquable du module LinkedIn de FlowDesk, proposée par HWS Agency.

**Aperçu en ligne : https://guenole.github.io/flowdesk-linkedin-apercu/**

Prototype de travail, non indexé par les moteurs de recherche. Il n'est relié à aucun service :
les actions restent dans le navigateur, et un rechargement de la page remet la démonstration à zéro.
La barre « Démo » (date simulée, « Vue de », réinitialisation) sert seulement à la présentation.
